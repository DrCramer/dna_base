# Changelog

## 2026-08-09

### Changed

- Проведён системный UI/UX polish основных рабочих экранов ДНК-реестра без изменения лабораторной бизнес-логики.
- Уплотнён интерфейс партий: заголовок и метаданные собраны компактнее, ежедневные действия получили приоритет, а массовые действия появляются только после выбора строк.
- Унифицированы `PageHeader`, состояния загрузки/ошибки/пустых данных, статусные бейджи, прогресс этапов, зоны загрузки файлов, выбор нескольких партий и панель действий с выбранными строками.
- Поля редактируемых таблиц визуально приближены к Excel/LIMS: нейтральный фон и рамка появляются при наведении или фокусе.
- Отчёты и импорты используют общий выбор партий и общие dropzone; служебные инструменты RT свёрнуты по умолчанию.
- Экспорт стал контекстным: состав полей зависит от режима, активный режим имеет явный индикатор, этапы отделены от дополнительных данных, preview показывает количество партий и объектов.
- История попыток этапа переведена в компактную таблицу с датой, номером попытки, источником, исполнителем и комментарием.
- Wizard печати DOCX получил динамический pipeline стадий и явное пояснение о фоновой обработке на сервере; дублирующая верхняя кнопка скачивания переведена во вторичное действие.
- Карточка объекта получила содержательные empty states и блокировку кнопки сохранения при отсутствии изменений.
- Модальные окна получили общий focus trap, закрытие по `Esc`, autofocus и возврат фокуса на вызвавший элемент.

### Fixed

- Исправлены переносы заголовков рабочих таблиц по буквам.
- Незапущенные этапы с прогрессом `0%` больше не выглядят ошибкой или предупреждением.
- Исправлены противоречивые loading/count состояния объектов, сотрудников и отчётов.
- Исправлена доступность реального drag-and-drop в общих зонах импорта файлов.
- Проверена адаптивность основных экранов без document-level горизонтальной прокрутки на `1920×1080`, `1600×900`, `1366×768` и `1280×720`.

- Предпросмотр авторегистрации уплотнён до одной раскрываемой таблицы; счётчик PDF для новых партий теперь равен числу партий, а `report.csv` убран из ZIP с партийными PDF.
- В авторегистрации DOCX + Excel порядок задаёт Excel, а каждый DOCX теперь подбирается по совпадающему № в в/ч №522 в имени файла; добавлена поддержка составных номеров вида `и8695-3`.
- Исправлена авторегистрация из DOCX + Excel: Excel с № в в/ч №522 теперь сохраняется внутри задания на сервере и не теряется после обновления страницы; все 1264 номера из общего списка читаются по колонкам сверху вниз, а PDF собираются по партиям с именами вида `194_ии8828-ии6305.pdf`.

Все заметные изменения, исправления и апгрейды проекта фиксируются в этом файле.

Формат:

- `Added` - новые возможности.
- `Changed` - изменения существующего поведения.
- `Fixed` - исправления ошибок.
- `Data` - ручные корректировки данных/миграционные действия.
- `Verified` - важные проверки после изменения.

- Исправлен импорт `Заполнение реестра`: поддерживается короткий заголовок колонки, а событие пробоподготовки создаётся даже если остальные поля этапа ещё пусты; старые объектные значения также отображаются в таблице.

- В отчётах появились KPI по активным партиям, объектам, незавершённым этапам, повторным этапам и признакам `Нет объекта`, `Нет постановления`, `Нет биоматериала`, `Горелая кость`.

- В `Массовом заполнении` добавлен `Импорт общего списка`: Excel с несколькими партийными колонками разбирается в preview, партии создаются/обновляются пачкой, `№ в в/ч №522` заполняется из файла, а новые объекты получают описание `кость`.
- При создании новых объектов вручную и через массовую регистрацию поле `Описание / комментарий` теперь по умолчанию заполняется значением `кость`, чтобы на этапе `Пробоподготовка` сразу был базовый тип материала.
- В массовом заполнении обычных этапов убран лишний preview-блок: предпросмотр остается только на этапе `Регистрация`, а остальные этапы снова работают компактно для быстрого заполнения одного столбца.

- В массовом заполнении `Регистрация` добавлен режим обновления существующих объектов партии: текущие строки подгружаются в preview, а ввод полей вроде `Коробка` больше не вызывает мигание модального окна из-за постоянного пересчёта preview.

- В массовом заполнении `Регистрация` preview-таблица больше не исчезает при вводе `Список № в в/ч №522`; preview автоматически обновляется и сразу показывает раскладку номеров по строкам.
- Модальное окно `Добавить объект` в партии переведено на отдельную адаптивную сетку: поля больше не вылезают вправо и не создают горизонтальную прокрутку при увеличенном масштабе интерфейса.
- В модальных окнах массового заполнения выровнены размеры всех полей: `input`, `select` и кнопки выбора сотрудников теперь занимают одинаковую ширину и высоту на всех этапах.

- В рабочих таблицах этапов колонка `Действия` скрыта по умолчанию и доступна через меню `Столбцы`; длинные служебные заголовки RealTime/PCR/электрофореза/анализа сокращены только для UI, без изменения экспортных заголовков реестра.

- Preview импорта реестра теперь показывает дубликаты из другой партии как `database_other_party` и отображает номер текущей партии объекта.
